Myautoclicker
A lightweight, windowed Python auto clicker with a clean dark UI and a global F6 toggle.

Features
Adjustable speed: 1–100 clicks per second (CPS).
Global hotkey: Press F6 to start or stop clicking.
Modern interface: Minimal dark theme with blue accents.
Live status: See whether clicking is active.
Click counter: Track the number of clicks performed.
Lightweight: Built with Python and Tkinter.
Requirements
Python 3.10 or newer recommended
Windows
pynput
Installation
Clone the repository:
   git clone https://github.com/YOUR-USERNAME/Myautoclicker.git
Open the project directory:
   cd Myautoclicker
Install dependencies:
   python -m pip install -r requirements.txt
Run the application:
   python autoclicker.py
Controls
Control	Action
F6	Toggle auto clicking
Start Clicking	Begin left-clicking
Stop Clicking	Stop left-clicking
CPS slider	Adjust click speed
Close window	Exit the application
